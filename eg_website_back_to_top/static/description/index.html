Website Back to Top

Website Back to Top adds a floating navigation button that helps visitors instantly return to the beginning of long website pages. The button automatically appears after the visitor scrolls down and remains hidden when it is not required, keeping the page design clean and distraction-free. It supports smooth scrolling, responsive positioning, keyboard navigation, screen readers, mobile safe areas, and reduced-motion preferences. Administrators can enable or disable the complete feature from the centralized INKERP settings without modifying website templates or source code.

Features

Central Enable and Disable Setting

Administrators can control the complete Back to Top functionality from the centralized INKERP settings section. The master checkbox allows the feature to be enabled or disabled without uninstalling the application or editing website templates. Once saved, the selected configuration is automatically applied across website pages.

Automatic Scroll-Based Visibility

The floating button remains hidden while visitors are near the top of the page and automatically appears after they scroll beyond the configured distance. This prevents unnecessary interface elements from occupying space when they are not needed.

Responsive Mobile-Friendly Design

The button automatically adjusts its size and screen position for desktop, tablet, and mobile devices. Safe-area support keeps it correctly positioned on devices with rounded screens, navigation indicators, or display notches. The responsive layout ensures that the button remains visible without blocking important website content.

2.) Use the Back to Top Button on the Website :

After the visitor scrolls down a long website page, the circular arrow button appears in the bottom-right corner. Clicking the button smoothly returns the visitor to the top of the current page. Its responsive placement keeps the control easy to reach while avoiding interference with product cards, pagination, and website content.
